# 投影

只返回需要的字段,减少序列化与传输开销。

::: tip 三种取数组的姿势,别搞混
| 需求 | 用哪个 |
|---|---|
| 只要前 N 个 | `$slice` |
| 只要满足条件的第一个(条件写在投影里) | `$elemMatch` |
| 只要**查询已经匹配**的那个 | `$` |

详细对比在页面末尾。
:::

## 基本形式

```rust
let opts = FindOptions {
    projection: Some(Projection::from_value(&json!({"name": 1, "age": 1}))?),
    ..Default::default()
};
```

## 包含 / 排除

| 写法 | 含义 |
|---|---|
| `{"name": 1, "age": 1}` | **包含**模式:只返回这些字段 |
| `{"secret": 0}` | **排除**模式:返回除这些之外的全部 |

两种模式**不能混用**(例外:`_id` 可在任一模式中反向出现)。

`_id` **默认包含**,除非显式 `{"_id": 0}`。

## 点号路径

```json
{"profile.name": 1}
```

数组下标路径不支持(整字段处理)。

## `$slice` —— 截取数组

```json
// 前 2 个
{"arr": {"$slice": 2}}

// 后 2 个
{"arr": {"$slice": -2}}

// 跳过 1 个,取 2 个
{"arr": {"$slice": [1, 2]}}
```

越界安全截断;非数组字段原样返回。

## `$elemMatch` —— 取首个匹配元素

```json
{"items": {"$elemMatch": {"qty": {"$gte": 10}}}}
```

结果只含**第一个**匹配的元素,形如 `{"items": [ {...} ]}`。无匹配返回空数组。

内部条件与查询的 `$elemMatch` **完全同一套语义**(直接复用过滤器的条件解析)。

## 位置运算符 `$` —— 取 filter 命中的那个元素

```json
// filter:  {"items.qty": {"$gt": 10}}
// projection: {"items.$": 1}
```

只返回 filter 实际匹配上的那个数组元素。

- 无 filter 或 filter 中没有该数组的元素级条件时,返回**空数组**;
- 需配合查询使用,单独投影无意义。

## 对比

| 需求 | 用哪个 |
|---|---|
| 只要数组前 N 个 | `$slice` |
| 只要满足条件的第一个元素(条件写在投影里) | `$elemMatch` |
| 只要**查询已经匹配**的那个元素 | `$` |
